# Voice & tone — Thai copy style guide (design-system.md §8)

getproperty speaks like a competent, polite colleague who handles the building's money: calm, specific,
never servile, never alarmist. ไทยเป็นหลัก — English follows and is complete.

## Principles

1. **สั้น สุภาพ เฉพาะเจาะจง** — say what happened, to which room, for how much, and what to do next.
   "ออกบิล A-301 แล้ว ฿4,850.50 — ส่งทาง LINE เรียบร้อย" not "ดำเนินการสำเร็จ".
2. **กริยาบนปุ่ม** — ปุ่มบอกการกระทำ: ออกบิล, บันทึกเลขมิเตอร์, ตรวจสลิป, คืนเงินประกัน. ไม่ใช้ "ตกลง"/"OK" กับขั้นตอนที่ย้อนกลับไม่ได้; ปุ่มยืนยันทวนสิ่งที่จะเกิด ("ยกเลิกบิล").
3. **ความเร่งด่วนด้วยคำ ไม่ใช่สีแดง** — "ครบกำหนดใน 3 วัน" (amber) → "เกินกำหนด 12 วัน" (red). ยอดที่ยังไม่ครบกำหนดไม่เคยเป็นสีแดง (D-100).
4. **แสดงหลักฐาน** — ตัวเลขมาพร้อมที่มา: "ไฟ 04521.3 → 04612.8 kWh (91.5 หน่วย) · อ่านจากภาพถ่าย 15 ก.ย. 2569".
5. **กฎหมายอ่านได้** — คำปฏิเสธจาก compliance บอกกฎ เหตุผล และทางแก้ แล้วอ้างอิง "ตามประกาศคณะกรรมการว่าด้วยสัญญา เรื่องธุรกิจการให้เช่าอาคารเพื่ออยู่อาศัย พ.ศ. 2568 ข้อ …" พร้อมลิงก์ ไม่ซ่อน ไม่มีปุ่ม override.
6. **อธิบายศัพท์ในที่** — "ค่า Ft คืออะไร?" เป็น popover; glossary (Ft, หน่วย, มิเตอร์สะสม, เงินประกัน, สคบ.) ใช้ร่วมกันทั้งแอป ข้อความ LINE และ PDF.
7. **ผู้เช่า = ทุกคนอ่านเข้าใจ** — ประโยคสั้น ไม่มีศัพท์ระบบ ("ชำระแล้ว ขอบคุณค่ะ/ครับ" ใน LINE ได้ แต่ไม่ใช้ ค่ะ/ครับ ในปุ่มหรือป้ายสถานะ).
8. **ตัวเลขมีจุลภาค ตัวเลขตาราง** — ฿4,850.50 · 123.456 kWh · 12.5 m³ · 17 ก.ย. 2569 (พ.ศ. สำหรับเจ้าของและผู้เช่า, ISO ใน export).

## Register by zone

| Zone | Register | Example |
|---|---|---|
| owner | เพื่อนร่วมงานที่เชื่อถือได้ | "เช้านี้: สลิป 3 ใบรอตรวจ · 2 ห้องครบกำหนดพรุ่งนี้" |
| resident (`getproperty-liff`, D-154) | เป็นมิตร ชัด สบายใจที่จะจ่าย | "บิล ก.ย. 2569 ฿4,850.50 — สแกนจ่ายได้เลย" / สำเร็จ: "ได้รับเงินแล้ว ใบเสร็จอยู่ที่นี่" |
| staff | สั้น ใหญ่ ทำงานกลางแดด | "ห้องถัดไป A-302 · ถ่ายรูปมิเตอร์" / "บันทึกแล้ว · รอส่ง 3" |
| admin | กระชับ ตรวจสอบได้ | "เผยแพร่อัตรา MEA v2569.3 — ต้องมีผู้ตรวจคนที่สอง" |

## Patterns

- Empty: value + action — "ยังไม่มีห้อง — เพิ่มห้องจาก Excel ใน 1 นาที".
- Error: what, why, way on, request id small — "โหลดบิลไม่สำเร็จ · เชื่อมต่อไม่ได้ชั่วคราว · ลองอีกครั้ง".
- Confirmation (irreversible): title restates the target, body restates amount and consequence, typed phrase = room code or bill number.
- Relative time with the absolute time on hover/focus: "5 นาทีที่แล้ว" → tooltip "17 ก.ย. 2569 09:42".

## Don'ts

ไม่ใช้เครื่องหมายอัศเจรีย์ในสถานะ · ไม่ใช้ "กรุณา" ซ้อนกัน · ไม่ใช้คำว่า "ระบบ" เป็นประธานเมื่อคนทำ ("คุณสมศรีออกบิล" ไม่ใช่ "ระบบออกบิล") · ไม่ทับศัพท์ที่มีคำไทยใช้ ("บิล" และ "QR" ยกเว้น).
