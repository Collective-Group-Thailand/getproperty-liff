# Tokens (ADR-0003)

Three tiers, authored in TypeScript (`src/ui/tokens`) and generated into `src/ui/generated/tokens.css`
by `pnpm tokens`:

1. **Primitives** — OKLCH palettes on one shared lightness ramp (`brand`, `neutral`, `green`, `amber`, `red`, `blue`), the logo's own hex values (`BRAND`) and the warm paper. Never used by a component.
2. **Semantic** — what a colour means, per theme: `bg`, `surface`, `fg`, `muted`, `primary`, `warning-subtle`… These are the only colours a component may name (`bg-surface`, `text-muted`).
3. **Component** — CVA variants inside each component, written only in semantic utilities.

Every text and UI pair is asserted at WCAG 2.2 AA in **light, dark and high contrast** by
`scripts/check-contrast.ts`, which runs inside `pnpm test`. A new semantic key that no pair mentions fails the gate.

Fonts (ADR-0001): **Noto Sans Thai** for UI, **Anuphan** for display, **JetBrains Mono** for bill numbers and meter
registers — self-hosted, Thai + Latin subsets, no Google Fonts at run time. Thai body line-height is 1.6; the staff zone
raises the base size to 18 px.
